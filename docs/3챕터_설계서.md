# SERA 3챕터 설계서 · 에코

2챕터 **디스패처**를 멈췄지만 화물선은 이미 바다로 떠났습니다. 3챕터 **에코**는 그 화물선을 따라 켈더 해상 기지로 갑니다. 거기서 세라는 3년 전 사고 때 죽은 줄 알았던 옛 동료 에코와 마주합니다. 이 문서에는 3챕터의 이야기, 새 능력 **반사**, 새 적과 기믹, 스테이지 배치와 보스 공략을 정리했습니다. 3챕터는 모두 구현되어 있습니다.

## 1. 정한 것

| 항목 | 결정 |
|---|---|
| 크기 | 3막 9스테이지. 막의 마지막 스테이지가 보스전 (보스 3) |
| 이야기 | 2챕터 설계서 10장의 방향 그대로. 에코, 켈더 해상 기지, 마지막에 '설계자' 암시 |
| 새 능력 | 반사. 좌클릭으로 막는 중 탄이 닿기 직전에 우클릭하면 탄이 온 길로 되돌아갑니다. W를 누르고 있으면 대각선 위로 갑니다 |
| 새 적 | 거울 포대, 흡수 경비, 추적탄 발사기 |
| 새 기믹 | 기우는 갑판(굴러오는 화물 통), 반사 표적, 저중력 실험실 |
| 최종 보스 | 에코. 세라와 같은 크기로 뛰고 미끄러지고 내리꽂는 거울 대결 |
| 끝 | 클리어 화면 뒤 에필로그를 보여 주고 타이틀로. 이야기는 다음으로 열어 둠 |
| 난이도 | 여러 번 죽으며 익히는 수준. 체크포인트는 스테이지마다 둘 |
| 안내 | 처음 나오는 것만 말풍선으로 한 번. 1·2챕터에서 배운 것은 다시 안내하지 않음 |
| 그림 | 적과 보스는 코드로 그린 도형. 배경은 코드로 그린 원경(바다, 선창, 켈더 플랫폼, 파이프, 시추탑, 실험동). 그림 파일을 넣으면 그것으로 바뀜 |
| 길이 | 2챕터와 비슷하게 (스테이지 6,600~7,000, 3-8은 세 층 4,700) |
| 테스트 | 새 스테이지는 열림 확인 (`tests/chapter3_open_test.gd`) |

## 2. 이야기

**한 줄 요약**: 세라는 화물선을 따라 켈더 해상 기지에 닿습니다. 바퀴와 항구에서 모은 운동량은 실험동으로 흘러가고 있고, 그 끝에서 에코가 기다립니다. 세라는 에코를 멈추지만, 이 모든 것을 그린 '설계자'가 따로 있다는 것을 알게 됩니다.

| 막 | 이름 | 스테이지 | 이야기 |
|---|---|---|---|
| 1막 | 항해 | 화물선 갑판 → 선창 → 키잡이 | 세라가 화물선에 올라탑니다. 보조 관제가 이번에도 슈트를 고쳐 놓았습니다(반사). 컨테이너 안에는 바퀴와 항구에서 모은 운동량이 있습니다. 키잡이를 멈추자 배가 켈더 플랫폼에 부딪힙니다. |
| 2막 | 플랫폼 | 계류 데크 → 파이프 랙 → 시추 리그 | 3년 만에 켈더에 왔습니다. 기지는 깨어 있었고, 에코의 호출 부호가 울립니다. 흡수 경비는 에코의 슈트와 같은 방식으로 움직입니다. 사고 기록의 생존자는 세라 한 명이었습니다. |
| 3막 | 반향 | 중력 시험동 → 반향실 → 에코 | 세라와 에코가 함께 슈트를 시험하던 곳입니다. 3년 전 실험을 멈춘 것은 세라였고, 에코는 그때 남겨졌습니다. 세라는 에코를 멈춥니다. |

**에필로그**: 에코는 세라 슈트의 제한을 푼 것이 자기가 아니라고 말합니다. 1~3챕터 내내 세라를 도운 보조 관제 신호는 켈더에서 온 것이 아니었습니다. 바퀴도, 항구도, 기지도 한 사람의 설계도였고, 그 끝에 '설계자'가 있습니다.

모든 문구(스테이지 이름, 대사, 클리어 문구, 보스 이름, 말풍선, 에필로그)는 `texts.gd`에 있습니다. 3챕터 문구는 `STAGES`의 "3챕터 · 에코" 아래와 18~22번 묶음입니다. 에필로그 줄 수는 바꿔도 됩니다.

## 3. 반사

| 항목 | 규칙 |
|---|---|
| 조작 | 좌클릭을 누른 채(막는 자세) 탄이 손에 닿기 직전에 우클릭. 3챕터 3-1부터 (`scripts/campaign.gd`의 `REFLECT_FROM`) |
| 시간 | 우클릭 뒤 0.22초 안에 탄이 손에 닿아야 합니다(정밀 흡수와 같은 길이). 아무것도 오지 않으면 0.42초 동안 다시 반사할 수 없습니다. 우클릭을 연타하지 못하게 하려는 것입니다 |
| 방향 | 탄이 온 길로 똑바로 되돌아갑니다. W를 누르고 있으면 대각선 위로 갑니다. 되돌린 탄은 1.3배 빠르고 금색입니다 |
| 운동량 | 얻지 않습니다. 받을지(운동량) 되돌릴지(공격) 고르게 됩니다 |
| 공중 | 공중 흡수처럼 공중에서도 됩니다. 머리 위로 지나가는 높은 탄은 뛰어서 반사합니다 |
| 반사되는 것 | 파란 탄, 큰 탄(관성탄, 흡수 경비의 탄), 추적탄. 바닥 파동, 컨테이너, 화물 통은 반사되지 않습니다 |
| 되돌린 탄이 맞히는 것 | 포대와 거울 포대(파괴), 추적탄 발사기(파괴), 흡수 경비(큰 탄이면 쓰러짐, 작은 탄은 먹고 큰 탄으로 돌려줌), 가드(충격파처럼 맞음, 방패와 차폐는 막음), 드론, 투하기, 반사 표적, 릴레이 |

3챕터에서는 좌클릭을 누른 채 우클릭하면 충격파가 나가지 않습니다. 충격파를 쏘려면 좌클릭을 놓고 우클릭합니다. 일시 정지 화면의 조작표 아래에 반사 줄이 더해집니다.

## 9. 다음 이야기

에필로그는 '설계자'를 남기고 끝납니다. 4챕터를 만든다면 이런 방향을 생각해 두었습니다.

- 보조 관제 신호의 발신지를 쫓습니다. 1~3챕터에서 세라의 능력을 하나씩 풀어 준 쪽입니다.
- 설계자는 세라의 슈트를 만든 사람이고, 바퀴(운동량), 항구(운송), 켈더(실험)를 이어 무언가를 준비하고 있었습니다.
- 반사까지 배운 세라에게 남은 것은 "받은 힘을 어디로 돌려줄지 고르는 것"입니다.

## 10. 고치거나 새로 만들 때

- 일반 스테이지의 지형과 기믹은 씬의 노드입니다. 규칙은 2챕터와 같습니다(`Walkways`, `Checkpoints`, `AimPads`, `DownSpots`, `Exit`). 반사 표적을 위로 맞히는 자리에는 `AimPads` 표식을 둡니다.
- 위로 반사하는 표적은 손에서 오른쪽 위 45도 선 위에 둡니다. 손은 표식에서 앞으로 36, 바닥에서 위로 85에 있으므로, 표적이 손보다 높은 만큼 손에서 오른쪽으로 떨어져 있어야 합니다. 예: 바닥 520, 표식 2560 → 손 (2596, 435) → 표적 (2730, 300).
- 기우는 갑판: 씬의 `World` 아래에 `ship_sway.gd` 노드 하나를 둡니다. `pattern`의 R은 오른쪽으로 기울어 오른쪽으로 미끄러지는 것, L은 그 반대입니다. 통 걸이는 갑판 위 레인의 왼쪽 끝에 두고 `length`를 레인 길이에 맞춥니다. 레인이 다른 블록을 지나지 않게 합니다.
- 저중력 구역: 노드가 구역의 왼쪽 아래 모서리입니다. `off_time`이 0이면 늘 켜져 있습니다. `enabled`를 끄면 아무것도 하지 않습니다(에코 전투에서 3페이즈에만 켬).
- 거울 포대는 `turret.gd`에 `mirror = true`를 켠 것입니다.
- 4챕터를 붙일 때는 `campaign.gd`의 `SCENES`, `ART`와 `texts.gd`의 `CHAPTERS`, `STAGES`에 더하고, 3-9 에코 씬의 `next_scene`을 4챕터 첫 스테이지로 바꿉니다. 에필로그는 캠페인의 마지막 스테이지에서만 나옵니다.
