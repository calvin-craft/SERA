# SERA 2챕터 설계서 · 디스패처

1챕터 **포어맨**은 사실상 튜토리얼입니다. 본격적인 게임은 2챕터 **디스패처**와 3챕터에서 시작합니다. 이 문서는 2챕터의 이야기, 새 능력과 적, 스테이지 배치를 정리하고, 3챕터의 방향을 적어 둡니다. 2챕터는 모두 구현되어 있습니다. 3챕터도 10장의 방향대로 만들었고, 자세한 내용은 [3챕터_설계서.md](3챕터_설계서.md)에 있습니다.

## 1. 정한 것

| 항목 | 결정 |
|---|---|
| 크기 | 챕터마다 3막 9스테이지. 막의 마지막 스테이지가 보스전 (챕터당 보스 3) |
| 1챕터 | 그대로 둠 |
| 새 능력 | 공중 흡수, 아래로 방출 (2챕터) · 반사 (3챕터) |
| 난이도 | 단계적으로. 2챕터는 1챕터보다 확실히 어렵게, 3챕터는 여러 번 죽으며 익히는 수준. 체크포인트는 스테이지마다 두 개 |
| 안내 | 처음 나오는 적·기믹·능력만 말풍선으로 한 번. 1챕터에서 배운 조작은 다시 안내하지 않음. 이야기 대사는 스테이지마다 |
| 새 요소 | 챕터마다 적 2~3종, 기믹 2~3종 |
| 그림 | 적과 보스는 코드로 그린 도형. 배경은 코드로 그린 원경(해안·철교·조차장·부두·방파제·관제탑). 그림 파일을 넣으면 그것으로 바뀜 |
| 길이 | 1챕터보다 조금 길게 (스테이지 6,000~7,000) |
| 챕터 선택 | 새 게임은 1챕터부터. 챕터를 한 번 깨면 다음 챕터부터 시작 가능 |
| 스테이지 연습 | 챕터 탭으로 나눔. 1챕터는 처음부터 열림, 2챕터부터는 캠페인에서 도달한 스테이지만 열림 |
| 테스트 | 새 스테이지는 열림 확인만 (`tests/chapter2_open_test.gd`) |
| 이야기 끝 | 3챕터 뒤로 열어 둠 |

## 2. 이야기

**한 줄 요약** — 대관성륜을 멈춘 뒤에도 제철소의 화물은 계속 나간다. 그 흐름을 쫓아 항구로 내려간 세라는, 모든 걸 실어 보낸 배차 지능 디스패처와 마주한다. 그러나 화물선은 이미 바다로 떠났다.

| 막 | 이름 | 스테이지 | 이야기 |
|---|---|---|---|
| 1막 | 추격 | 해안 선로 → 절벽 철교 → 장갑 열차 | 바퀴는 멎었는데 화물 열차가 계속 나간다. 열차 무전에서 '디스패처'라는 이름이 잡힌다. 포어맨도 디스패처의 지시를 받고 있었다. |
| 2막 | 부두 | 조차장 → 컨테이너 부두 → 스트래들 캐리어 | 보조 관제가 슈트의 방출 제한을 푼다. 컨테이너마다 같은 행선지, 켈더 해상 기지. 3년 전 그 실험이 있던 곳이다. |
| 3막 | 출항 | 방파제 → 항만 관제탑 → 디스패처 | 관제탑의 기록에 3년 전 사고 보고서가 있고, 거기 세라의 이름이 있다. 디스패처를 멈추지만 화물선은 수평선 너머로 사라진다. |

모든 문구(스테이지 이름, 대사, 클리어 문구, 보스 이름, 말풍선)는 `texts.gd`에 있습니다. 2챕터 문구는 `STAGES`의 "2챕터 · 디스패처" 아래와 14~17번 묶음입니다.

## 8. 타이틀과 저장

- **새 게임**은 1챕터부터입니다. 1챕터를 한 번 깨면(대관성륜 클리어) 새 게임에서 챕터를 고르는 화면이 뜨고, 2챕터부터 바로 시작할 수 있습니다.
- 1챕터를 깨면 클리어 화면 뒤 E로 2챕터 시작 카드가 이어집니다. 새 챕터는 운동량 0에서 시작합니다.
- **스테이지 연습**은 위쪽 오른쪽의 챕터 탭(또는 PgUp/PgDn)으로 챕터를 넘깁니다. 2챕터 카드는 캠페인에서 들어가 본 스테이지까지만 열리고, 나머지는 잠김으로 보입니다.
- 저장 파일에 `reached`(캠페인에서 도달한 가장 먼 스테이지)가 더해졌습니다. 예전 저장은 기록과 이어하기 위치로 계산해 그대로 이어집니다.

## 9. 확인한 것과 직접 봐 주셔야 할 것

자동으로 확인한 것:

- `tests/chapter2_open_test.gd`: 2챕터 아홉 스테이지가 오류 없이 열리고 몇 초 동안 돌아가며, 능력이 맞게 켜지고, 문구와 다음 스테이지가 연결되어 있고, 캠페인으로 들어가면 2챕터 시작 카드가 뜹니다.
- 기존 테스트 전부(1챕터 아홉 스테이지 자동 플레이, 캠페인, 문구, 소리).
- 저장소에 넣지 않은 임시 점검으로 위험한 동작을 한 번씩 해 봤습니다: 아래로 방출로 220 벽 넘기, 해치 깨고 아래 통로로, 열차에 서 있으면 다음 갑판까지 실려 감, 높은 포대의 탄을 공중 흡수, 장갑 열차 관성탄 → 코어 명중, 캐리어 컨테이너 → 지붕 → 코어 명중, 디스패처 관성탄 → 대각선 명중, 방패 경비를 위에서 쓰러뜨리기.

직접 봐 주셔야 할 것:

1. 새 스테이지를 처음부터 끝까지 깨는 자동 테스트는 없습니다. 스테이지 연습이나 F6으로 2-1부터 2-9까지 한 번씩 끝까지 가 봐 주세요. 막히는 곳이 있으면 위치를 알려 주시면 고치겠습니다.
2. 손맛과 난이도: 돌풍 틈의 타이밍, 열차 타는 동안의 포대, 캐리어 지붕 위 흔들기 시간, 디스패처 3페이즈의 바람.
3. 코드로 그린 원경과 적·보스 도형이 읽히는지.

- **이름(안)**: 에코. 3년 전 사고 때 죽은 줄 알았던 세라의 옛 동료 흡수 요원의 호출명입니다. 그는 받은 힘을 그대로 되돌리는 시제품 슈트를 입고 있습니다.
- **장소**: 화물선이 향한 켈더 해상 기지. 1막 바다 위 화물선, 2막 해상 플랫폼, 3막 실험동.
- **새 능력**: 반사. 정밀 흡수 타이밍에 우클릭하면 탄을 운동량 없이 되돌립니다. 최종 보스 에코는 세라의 충격파를 흡수해 되돌리므로, 반사로만 틈을 만들 수 있게 합니다.
- **새 요소 후보**: 흔들리는 갑판(배가 기울면 굴러가는 화물), 자석 크레인, 되돌려 쏘는 거울 포대, 저중력 실험실.
- **끝**: 에코를 멈추지만, 그를 보낸 '설계자'의 존재가 드러나며 다음 이야기를 남깁니다.

## 11. 고치거나 새로 만들 때

- 일반 스테이지의 지형과 기믹은 씬의 노드입니다. 1챕터와 같은 규칙(`Walkways`, `Checkpoints`, `AimPads`, `Exit`)에 `DownSpots`(아래로 방출 안내가 뜨는 바닥 지점)가 더해졌습니다.
- 열차: 노드는 도랑의 왼쪽 갑판 끝에 두고 `span`을 도랑 너비에 맞춥니다. 도랑 양쪽 갑판의 높이는 같아야 합니다.
- 돌풍: 노드가 구역의 왼쪽 아래 모서리입니다. `off_time`이 0이면 계속 붑니다.
- 해치: 갑판 사이의 틈을 덮도록 둡니다. 한 번 깨진 해치는 체크포인트에서 이어도 깨진 채입니다.
- 높이 220 이상의 벽은 아래로 방출로만 넘을 수 있습니다(점프+에너지 도약은 213). 높이 160은 점프+도약으로도 오릅니다.
- 새 챕터를 붙이는 방법은 `docs/스테이지_설계서.md` 8장에 있습니다. 3챕터를 붙이면서 2-9 디스패처 씬의 `next_scene`을 3-1 화물선 갑판으로 바꿨습니다.
